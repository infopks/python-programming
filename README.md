# Python Programming

A 45-day Python learning repository based on *Think Python: How to Think Like a Computer Scientist* (3rd edition) by Allen B. Downey.

## Current progress

### Chapter 1 — Programming as a Way of Thinking

Chapter 1 introduces the foundations of Python programming:

- Arithmetic operators: `+`, `-`, `*`, `/`, `//`, and `**`
- Values and types: `int`, `float`, and `str`
- String concatenation, repetition, and length
- Built-in functions such as `abs()`, `round()`, `type()`, `int()`, and `float()`
- Expressions, formal languages, syntax errors, type errors, and debugging

## Running the exercises

From the repository root, run:

```bash
python think-python-chapter-1-starter/python-programming/chapter-01/exercises.py
```

Or change into the project directory first:

```bash
cd think-python-chapter-1-starter/python-programming
python chapter-01/exercises.py
```

## Learning goals

By completing this chapter, you will practice:

1. Evaluating Python expressions and arithmetic operations.
2. Identifying common Python data types.
3. Working with strings and built-in functions.
4. Distinguishing syntax errors from type errors.
5. Predicting program output before running code.
