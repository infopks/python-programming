# Python Programming

A 45-day learning repository based on *Think Python: How to Think Like a Computer Scientist* (3rd ed., Allen B. Downey).

## Learning objectives
- Learn core Python syntax, functions, data structures, and object-oriented programming.
- Complete practical coding exercises and prepare for university exams.

## Structure
- `chapter-01/notes.md` — your Chapter 1 notes
- `chapter-01/exercises.py` — Chapter 1 coding practice
- `chapter-01/quiz.md` — quick knowledge check

## How to run
Run `python chapter-01/exercises.py` from the repository root.
